# EcoLife – Sustainable Living Website

## 1. Project Overview
EcoLife is a web-based project designed to promote environmental awareness and sustainable living through a website with interactive elements.

## 2. Technologies Used
- HTML
- CSS
- JavaScript
- Node.js and npm, if required by the project configuration

## 3. Project Files
- `home.html` – Main webpage, if this is the actual entry page
- `style.css` – Website styling
- `script.js` – Website interactions
- `package.json` – Project configuration and available scripts
- `package-lock.json` – Records the resolved npm dependency versions

## 4. Prerequisites
- A modern web browser
- Node.js and npm, if required by the configured scripts

## 5. Setup and Execution
1. Download or extract the project folder.
2. Open a terminal in the project directory.
3. Follow the installation and run commands specified in `package.json`.
4. Open the local URL provided by the development server, if applicable.

## 6. Deployment

## 7. Notes
Keep all required source files and assets in the project folder. Verify the setup and build commands against the actual project configuration before submission.
